Independent review of counter-only Arriba diagnostics — 5 October 2026

No intentional filtering, threshold or control-flow change found in the two supplied patches or their generator. The eight existing malformed-group goto statements retain their original conditions and destinations; diagnostics are added immediately before them. The wrong-clipped supplementary-record branch keeps its original malformed_count increment, adding logging afterward. Subsampling diagnostics occur only after the original subsampled_fusions=true statements and before the unchanged continue/break decisions. Diagnostic helper arguments are const references and do not mutate the fusion/read objects; helpers write their own maps/sets and stderr. Stock source/output paths are preserved and the diagnostic source is separate.

Independent bytewise comparison confirms accepted AND discarded fusion TSVs are identical for BOTH completed full-reference public controls (Arriba and STAR-Fusion synthetic sets). Four SHA256 pairs match in independent-public-control-compare.json. This is a bounded regression gate, not proof that every patient path is invariant; compare final patient accepted/discarded tables with stock as well.

Denominators must stay explicit. Malformed totals combine one event per rejected supplementary record with one event per rejected collated alignment group. The same biological fragment can contribute to both stages. Neither sum nor individual reason total is a unique-molecule count, percentage of raw reads lost, nor a calibrated sensitivity loss. The eight group reasons are mutually exclusive per pass through the goto rejection, not necessarily across all records from a fragment. The wrong-clipped-end total has a different counting unit. Compare their sum with the stock malformed warning only for the current one-input invocation.

The diagnostic maps are static and cumulative within a process. Arriba can call read_chimeric_alignments twice when a separate chimeric BAM is provided; the current pipeline uses only RNA BAM/stdin, so one invocation applies. If later using both input paths, repeated totals cannot be naively summed.

Subsampling totals count branch encounters, and the final number counts distinct diagnostic fusion keys. In particular, unfiltered_discordant_cap_break counts cap-triggered breaks, not every skipped remainder read; it cannot recover an exact skipped-fragment denominator. Split and filtered-discordant events may reuse a supporting fragment across fusion hypotheses. The comments accurately identify this distinction. Diagnostic keys use gene names, breakpoints/contigs/directions; describe these as distinct keys, not independent biological rearrangements.

Group/record examples are bounded at8 per reason; subsampling examples are bounded at30 distinct keys per reason. These are illustrative first encounters, not representative random samples. Additional map/set memory and stderr logging can affect runtime but no scientific decision change was introduced. No code edits or new patient computation were performed by this reviewer. A broad object-file hash walk was cancelled when file hydration stalled; it is not claimed as a completed binary reproducibility check.
